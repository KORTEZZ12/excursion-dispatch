# ADR-001. Вебхук amoCRM — сигнал, данные — из API

Статус: принято, уточнено в v0.4. Связано с D-04, US-01, NFR-04, NFR-06.

## Контекст

Заявки живут в amoCRM, её настраивал внешний интегратор, своего программиста у службы нет. У вебхуков amoCRM нет идентификатора события и подписи. amoCRM ждёт ответ не дольше 2 секунд, повторяет недоставленное и отключает хук, если невалидных ответов слишком много. `updated_at` сделки — целые секунды.

## Варианты

| Вариант | Плюсы | Минусы |
|---|---|---|
| Брать данные из тела вебхука | Нет лишних запросов | Тело неполное и повторяет структуру формы. Дубли и перестановки ломают данные. Поддельный запрос может их испортить |
| Опрашивать API по расписанию без вебхуков | Просто, всё под контролем | Задержка до интервала опроса, лишняя нагрузка на API |
| Вебхук как сигнал, данные из API, плюс сверка | Быстро и надёжно | Лишний запрос на каждое событие |

## Решение

Вебхук только сохраняется, ответ — сразу 200. Обработчик берёт сделку через `GET /api/v4/leads/{id}` и применяет её по `updated_at`:
- старше сохранённого — не применяется;
- то же время и те же данные — ничего не меняется;
- то же время, но другие данные — применяется. События одной сделки обрабатываются строго по очереди, поэтому более поздний ответ API не может быть старее сохранённого.

Раз в 15 минут сверка запрашивает сделки, изменённые с момента последней успешной сверки минус 5 минут.

## Последствия

- Дубли, перестановки и поддельные вебхуки не портят данные: правда — в API, порядок — по `updated_at` и очереди событий сделки (проверено в [`ddl-checks.sql`](../../design/ddl-checks.sql)).
- Две правки в одну секунду, например администратора и робота воронки, не теряются. В v0.3 вторая из них отбрасывалась навсегда: равное время считалось устаревшим, и сверка тоже её не подбирала (F-18).
- Один запрос к API на событие. При 12 заявках в день это ничто.
- Если хук отключат или диспетчер простоит несколько часов, заявки всё равно придут через сверку: она начинается с последней успешной, а не с «последнего часа», как в v0.3 (F-27). Сработает алерт.
