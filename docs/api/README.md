# Соглашения API

Версия 0.3. Контракт — [`openapi.yaml`](openapi.yaml): панель администратора и входящие вебхуки. Гиды работают через Telegram-бота, своего API у них нет.

## Проверка

```bash
npx @redocly/cli lint openapi.yaml          # без ошибок и предупреждений
npx @redocly/cli build-docs openapi.yaml    # HTML-документация
npx @stoplight/prism-cli mock openapi.yaml  # mock по примерам
```

## Правила

- **Конкурентные правки.** `GET` возвращает `ETag` с версией, изменяющие запросы к заявкам и назначениям требуют `If-Match`. Версия устарела — 412, нет заголовка — 428. Так две вкладки администратора не перетрут изменения друг друга.
- **Идемпотентность.** Создание заявки — с `Idempotency-Key`. Назначение (`PUT`), снятие гида (`DELETE`), отмена, «Взять в работу» и «Отправлено» идемпотентны сами: повтор возвращает тот же результат.
- **Ошибки** — RFC 9457 с полем `code`. У каждого кода есть действие для панели.
- **Вебхуки** отвечают сразу и обрабатываются асинхронно. Ответ 200 значит «сохранено», а не «обработано».

## Каталог ошибок

| code | HTTP | Когда | Что делает панель |
|---|---|---|---|
| VALIDATION_ERROR | 400 | Неверный формат поля | Подсвечивает поле из `errors` |
| UNAUTHORIZED | 401 | Сессия истекла | Просит войти и повторяет запрос |
| NOT_FOUND | 404 | Нет такой заявки, группы, гида | Обновляет список |
| BOOKING_FROM_CRM | 409 | Заявку из amoCRM меняют в панели | Показывает ссылку на сделку в amoCRM |
| OVERLAP_CONFIRMATION_REQUIRED | 409 | У гида пересечение | Показывает пересечения из `overlaps` и кнопку «Назначить всё равно» |
| GROUP_NOT_ASSIGNABLE | 409 | Группа отменена или проведена | Обновляет карточку группы |
| DUTY_OVERLAP | 409 | В это время уже есть дежурный | Показывает текущее дежурство |
| VERSION_CONFLICT | 412 | Группу или заявку изменили после чтения | Перечитывает и показывает, что поменялось |
| START_IN_PAST | 422 | Время начала в прошлом | Подсвечивает время |
| ROUTE_NOT_FOUND | 422 | Маршрута нет в справочнике | Предлагает выбрать маршрут |
| GUIDE_NOT_ACTIVE | 422 | Гид не подтверждён или деактивирован | Предлагает другого гида |
| PARAMETER_READ_ONLY | 422 | P-01 или P-06 | Объясняет, что параметр меняется релизом |
| PRECONDITION_REQUIRED | 428 | Нет `If-Match` | Дефект панели: в лог и мониторинг |
