API панели администратора и входящие вебхуки amoCRM и Telegram. Гиды работают через Telegram-бота, поэтому своего API у них нет. Соглашения — в README.

Изменяющие запросы к заявкам и назначениям требуют If-Match с версией из ETag: так две вкладки администратора не перетрут изменения друг друга.

Вебхук amoCRM

amoCRM ждёт ответ не дольше 2 с и отключает хук после сотни невалидных ответов за 2 часа. Поэтому тело сохраняется как есть и сразу возвращается 200, даже если событие не будет обработано. Данные сделки потом берутся из API amoCRM (ADR-001).
