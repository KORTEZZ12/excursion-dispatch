API панели администратора и входящие вебхуки amoCRM и Telegram. Гиды работают через Telegram-бота, поэтому своего API у них нет. Соглашения — в README.

Все изменяющие запросы панели требуют Idempotency-Key: повтор с тем же ключом возвращает результат первого выполнения, даже если версия ресурса уже сменилась. Правки заявок и назначений дополнительно требуют If-Match с версией из ETag: так две вкладки администратора не перетрут изменения друг друга.

Создать заявку в панели

Запасной путь, если заявка пришла мимо amoCRM (US-02). Группы и поиск гида создаются сразу. Повтор с тем же Idempotency-Key возвращает тот же ответ 201 и ту же заявку, второй заявки не будет.

adminAuth
header Parameters

required
string <uuid>
Example: 5f0e6a2b-7c1d-4e8f-9a3b-2c4d6e8f0a1b

Отменить заявку из панели

Повторная отмена возвращает 200 и ту же отменённую заявку. Гиды получают уведомление (BR-20). Заявку из amoCRM отменяют в amoCRM. Если amoCRM недоступна, администратор делает аварийную отмену (emergency: true): заявка отменяется сразу и помечается «Повторить в amoCRM» (BR-04). Отмена не требует If-Match: повтор безопасен, а отменённую заявку уже нельзя изменить.

Назначения

Ручное назначение и снятие гида, история группы

Назначить гида вручную

Повтор с тем же Idempotency-Key возвращает то же назначение. Открытое окно откликов закрывается без выбора, откликнувшиеся видят «Группу назначил администратор» (US-06, US-23). Назначить гида с пересечением нельзя (BR-09, D-13): ответ 409 GUIDE_BUSY с пересечениями, свободных гидов панель берёт из GET /v1/guides?freeForGroup=. Назначение позже чем за P-07 до начала сразу считается подтверждением выхода (BR-13). Если у группы был другой гид, это замена: прежний получает «Вы больше не ведёте группу».
