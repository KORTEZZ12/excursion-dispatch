# Самозапись времени администратора

Нужна для метрики «минут в день на сообщения гидам» ([видение](../requirements/vision.md#цели-и-метрики)): одна из трёх оценок 2–2,5 ч включала сбор переводов, а его MVP не автоматизирует. Заполняют все администраторы неделю до запуска пилота и неделю через месяц после.

Как заполнять: после каждого вечера одна строка, минуты по часам телефона, не по памяти в конце недели.

| Дата | Администратор | Сообщения гидам о группах на завтра, мин | Ответы гидам на уточнения, мин | Сбор переводов за наличные, мин | Отписки клиентам, мин | Сколько отписок | Комментарий |
|---|---|---|---|---|---|---|---|
| | | | | | | | |

Итог недели: среднее по каждому столбцу в минутах в день. В видение уходит первый столбец, остальные — в итоги исследования.
