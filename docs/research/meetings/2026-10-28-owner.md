# Встреча с владельцем службы, 28.10.2026

Формат: созвон. Длительность: около часа. Повестка — решения D-12–D-16 и вопросы Q-01–Q-04 из [видения](../../requirements/vision.md#эксплуатация-и-владелец).

## Решения

| ID | Решение | Ответ владельца |
|---|---|---|
| D-12 | MVP двумя релизами. Первый — без поиска гида в боте, администраторы назначают вручную, пилот на пяти гидах две недели параллельно с чатом | принято |
| D-13 | Гида с другой группой в это же время, с учётом буфера 30 минут, нельзя назначить даже вручную | принято |
| D-14 | Если диспетчер сломался или Telegram недоступен, администраторы получают тревогу не через Telegram | принято, канал — звонок |
| D-15 | Гид подтверждает выход один раз в день, перед первой группой; ранним группам запрос приходит в 07:00 | принято |
| D-16 | «Передана партнёру» — отдельный статус группы и главная метрика | принято |
