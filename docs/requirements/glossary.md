# Глоссарий

Версия 0.4.

| Термин | Значение |
|---|---|
| Заявка | Обращение клиента на экскурсию: дата и время, маршрут, число участников по категориям, контакт, способ оплаты. Ведётся в amoCRM |
| Группа | Часть заявки, которую ведёт один гид: от 1 до 15 участников. Заявка на 40 человек — три группы |
| Раунд поиска | Один поиск гида для группы: рассылка, окно откликов, выбор. Каждый возврат группы в поиск — новый раунд, отклики прошлого раунда в нём не действуют |
| Предложение | Сообщение гиду в боте о группе без гида с кнопками «Хочу взять» и «Пропустить» |
| Отклик | Нажатие «Хочу взять» до рассылки или в окне откликов — в предложении или в «Свободных группах». Гид становится кандидатом, группа ещё не его |
| Назначение | Закрепление гида за группой. У группы в каждый момент не больше одного назначенного гида. Замена гида — новое назначение |
| Свободные группы | Раздел бота со всеми группами без гида на ближайшие 14 дней |
| Мои группы | Раздел бота с группами гида на сегодня, завтра и следующие 7 дней |
| Сводка на завтра | Вечернее сообщение гиду со всеми его группами на следующий день. Заменяет личные сообщения администратора |
| Подтверждение выхода | Ответ гида «Подтвердить выход» на запрос перед первой группой дня. Подтверждает все его группы этого дня. Позднее назначение считается подтверждением само |
| Отписка | Сообщение клиенту накануне в его мессенджер: где и когда сбор, маршрут, как оплатить, имя и телефон гида. Термин из практики службы |
| Канал отписки | Мессенджер клиента — Telegram, MAX или WhatsApp. Клиент называет его при записи, администратор может сменить при отправке |
| Дежурный администратор | Администратор, который в текущую смену разбирает эскалации. Без графика дежурств — все администраторы |
| Эскалация | Сигнал, что процесс встал: гид не найден, нет подтверждения выхода, гид просит замену, отписка не отправлена к сроку, гид заблокировал бота |
| Передана партнёру | Исход группы, для которой гида не нашли и которую ведёт партнёрская служба. Главная бизнес-метрика проекта |
| Тихие часы | 22:00–07:00. Плановые сообщения в это время не отправляются |
| Маршрут | Программа экскурсии: название, длительность, место сбора со ссылкой на карту и фото, точки маршрута со временем от старта |
| Окно откликов | 10 минут, для срочных групп 2 минуты, от отправки последнего предложения раунда; в это время гиды откликаются, потом система выбирает одного (D-11) |
| Ручной режим | Работа по старой схеме, если диспетчер недоступен: администратор получает тревогу и рассылает гидам сводку сам (NFR-16) |
| Диспетчер | Разрабатываемая система: бот для гидов, панель администратора, планировщик сообщений |
| CRM | amoCRM — система учёта заявок, в которой работают администраторы. Настраивал внешний интегратор |
