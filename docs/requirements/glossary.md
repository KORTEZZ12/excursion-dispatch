# Глоссарий

| Термин | Значение |
|---|---|
| Заявка | Обращение клиента на экскурсию: дата и время, маршрут, число участников, контакт, способ оплаты. Ведётся в CRM |
| Группа | Часть заявки, которую ведёт один гид: от 1 до 15 участников. Заявка на 40 человек — три группы |
| Предложение | Сообщение гиду в боте о группе без гида с кнопками «Хочу взять» и «Пропустить» |
| Отклик | Нажатие «Хочу взять» в окне откликов. Гид становится кандидатом, группа ещё не его |
| Назначение | Закрепление гида за группой. У группы в каждый момент не больше одного назначенного гида |
| Свободные группы | Раздел бота со всеми группами без гида на ближайшие 14 дней |
| Мои группы | Раздел бота с группами гида на сегодня, завтра и следующие 7 дней |
| Сводка на завтра | Вечернее сообщение гиду со всеми его группами на следующий день. Заменяет личные сообщения администратора |
| Подтверждение выхода | Ответ гида «Подтвердить выход» на запрос за 2 часа до начала |
| Отписка | Сообщение клиенту накануне в его мессенджер: где и когда сбор, маршрут, как оплатить, имя и телефон гида. Термин из практики службы |
| Канал отписки | Мессенджер клиента — Telegram, MAX или WhatsApp. Клиент называет его при записи, администратор может сменить при отправке |
| Дежурный администратор | Администратор, который в текущую смену разбирает эскалации |
| Эскалация | Сигнал дежурному, что процесс встал: гид не найден, нет подтверждения, гид просит замену, отписка не доставлена, гид заблокировал бота |
| Тихие часы | 22:00–07:00. Плановые сообщения в это время не отправляются |
| Маршрут | Программа экскурсии по Иннополису: название, длительность, место сбора со ссылкой на карту и фото, точки маршрута со временем от старта |
| Окно откликов | 10 минут, для срочных групп 2 минуты, в течение которых гиды откликаются, прежде чем система выберет одного (D-11) |
| Диспетчер | Разрабатываемая система: бот для гидов, панель администратора, планировщик сообщений |
| CRM | Система учёта заявок, в которой работают администраторы. Конкретный продукт уточняется на интервью |
