# Изменения

## 0.5

Данные исследования и опрос гидов.

- В протоколах интервью проставлены даты, формат и длительность: интервью шли с 18 сентября по 3 октября 2026, с администраторами около 15 минут, с гидами 3–8 минут. Ограничения в итогах дополнены.
- Протокол 15 помечен как восстановленный по памяти: заметок этого разговора нет. В итогах показано, как без него меняются доли по гидам.
- Объём заявок уточнён у старшего администратора: в смену работает один администратор, новых заявок 5–12 в день. «2–3 в день» в протоколах — ошибка оформления, она отмечена в протоколах 01–03. С уточнением сходится объём, который назвали гиды.
- Опрос гидов (Г11), 32 ответа из 40: против гонки 24, за жребий 12, за «меньше групп на неделе» 7. Выбор гида внутри окна откликов — жребий (D-17, предложено): BR-06, US-23, ADR-002, функция `select_guide` и проверка в `ddl-checks.sql`.
- Встреча с владельцем службы 28.10.2026: приняты D-12–D-16, резервный канал тревог — звонок, свой диспетчер вместо настройки amoCRM, при передаче партнёру теряется вся выручка, город в портфолио указывать можно. Протокол — docs/research/meetings.
- По совету юриста номер клиента гиду не показывается: звонок через подменный номер (D-18, предложено), провайдер телефонии — новый вопрос Q-06. Правило отмены юрист устно не оспорил, письменная формулировка ждёт.
- Для самозаписи администраторов и разбора групп, отданных партнёрам, показан метод на модельных данных по интервью — до реальных замеров.
- Статусы в реестре ревью обновлены: закрыты F-10, частично F-24 и F-35.

## 0.4

Исправления по [независимому ревью итерации 2](docs/reviews/2026-10-27-iteration-2/README.md): 42 замечания, из них 12 критических. Новые решения D-12–D-16 предложены и ждут заказчика.

- Метрики видения переписаны: исход «Передана партнёру» (BR-35, US-28, D-16), доля групп, назначенных до срока эскалации, метрика честности распределения, базовая линия времени администратора без сбора переводов. Добавлены бизнес-кейс, сравнение «сделать или настроить», эксплуатация и вопросы Q-01–Q-05.
- MVP разделён на два релиза, первый — пилот на пяти гидах (D-12).
- Одно правило отклика для предложения и «Свободных групп», раунды поиска, повторный отклик после отзыва (BR-06, функция `respond`).
- Пересечение у гида запрещено без исключений, в том числе при ручном назначении (D-13); закрыта дыра с пустым диапазоном занятости.
- Подтверждение выхода — одно на день, ранним группам в 07:00, позднее назначение считается подтверждением (D-15). Замена гида не наследует подтверждение.
- «Попросить замену» работает всё время назначения, подтверждение после срока закрывает эскалацию: схема подготовки группы перестроена.
- «Отписка не отправлена к сроку» — эскалация всем администраторам; текст отписки собирается при показе и фиксируется при отправке.
- API: `Idempotency-Key` на всех изменяющих запросах, передача группы партнёру, график дежурств, E.164, JSON Merge Patch, `Location` у 201.
- amoCRM: правки в одну секунду не теряются, сверка с момента последней успешной, переходное правило для полей, которых пока нет в CRM.
- Резервный канал тревог и контроль тихого отказа (D-14, NFR-16); предел попыток и срок годности сообщений Telegram (NFR-08).
- Модель данных: причины отмены и отказа, журнал эскалаций и параметров, обезличивание имени, срок хранения вебхуков. `ddl-checks.sql` — 32 проверки вместо 13.
- Исследование: исправлены итоги Г1, Г7 и Г9, добавлены Г11 и Г12, раздел «Что не сходится», шаблон самозаписи времени.
- Архитектура контейнеров, макет доски администратора, SD-6 о позднем отказе.
- CI: модель данных в PostgreSQL 16, Redocly lint, bpmnlint с правилами Camunda 8.8, проверка ссылок.
